# Gym Coach

A personal gym coaching app that helps you plan, track, and optimize your workouts.

## Features

- **Workout Plans** — Pre-built and custom workout routines
- **Exercise Library** — Categorized exercises with instructions
- **Progress Tracking** — Log sets, reps, and weight over time
- **Rest Timers** — Configurable rest period countdowns between sets
- **Personal Records** — Automatically tracks your PRs
